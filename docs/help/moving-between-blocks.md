# Moving between blocks

A page holds blocks: text, images, tables, and code. On a document page they stack from top to bottom. On a freeform page, text boxes sit wherever you put them. These keys move between them without the mouse.

## In the flow of a document page

| Key | What it does |
|---|---|
| Up Arrow on the first line, Down Arrow on the last | Moves to the block above or below, near the same place in the line. An image is selected as a whole. |
| Shift+Up Arrow or Shift+Down Arrow past the edge of a block | Selects this block and the next as whole blocks. OpenNote says how many are selected. |
| Backspace at the very start of a text block | Joins it to the text block above, or selects the image or table above. |
| Ctrl+A | Selects all the text in the block. Press it again to select every block on the page. |
| Delete, with blocks selected | Deletes them. Undo in the message that appears, or Ctrl+Z, brings them back. |

## Leaving a text box

Arrow keys stay inside a floating text box. To leave it:

1. Press Escape. The text box is selected as an object.
2. Press Tab or Shift+Tab to go to the next or previous block in reading order.

With the box selected, the arrow keys nudge it, and Enter puts the caret back in its text. Screen readers announce "Press Escape, then Tab, to leave the text box" in every text box.

## Tab inside text

Tab stays inside the text, as it does in most editors:

- In a list, Tab indents the item and Shift+Tab outdents it.
- At the start of a paragraph, Tab turns it into a bulleted list item.
- Anywhere else, Tab types a tab character.
- In code blocks and tables, Tab keeps its own meaning: an indent in code, the next cell in a table.

## Moving items and headings

| Key | What it does |
|---|---|
| Alt+Shift+Up Arrow, Alt+Shift+Down Arrow | Moves the list item, with its children, or the heading, with its section, up or down. |
| Alt+Shift+Right Arrow, Alt+Shift+Left Arrow | Moves a list item or heading one level deeper or one level up. |
| Alt+Shift+1 to Alt+Shift+9, Alt+Shift+0 | Shows the outline down to that level, or shows everything. |

## Zooming the page

Ctrl+Alt+= and Ctrl+Alt+- zoom the page, and Ctrl+Alt+0 goes back to 100%. Ctrl+= and Ctrl+- change the size of text in all of OpenNote instead.
