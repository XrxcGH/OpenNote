# Text formatting

OpenNote formats text the way a word processor does. Some controls sit behind flags that are off in Stable. Settings, then Flags, turns them on.

## Fonts and text styles

- The Home tab has font and size boxes, bold, italic, underline, strikethrough, superscript, subscript, and colors. Size steps, change case, and the clear rules are in the command list (Ctrl+K).
- Carlito and Caladea come with OpenNote and stand in for Calibri and Cambria. They load only when a page uses them. The app also lists the fonts on this PC. Nothing about them leaves the device.
- The format painter copies the look of the text at the caret once, or locked for many places. Repeat redoes the last format.

## The Format pane

Press Ctrl+D for Font, or choose Paragraph. One pane has every text and paragraph field: tab stops, borders, shading, and list levels. Values take pt, in, cm, mm, px, or pc. A bad value shows its allowed range. Reveal formatting lists each format and where it comes from. Modify on a style edits the style. Flag: text.formatPane.

## The ruler

Choose View, then Ruler. The ruler sits above the text with the caret and uses the unit you choose, at any zoom. Drag the first line, hanging, left, and right indent markers. Add, move, or remove tab stops. The markers also work with the arrow keys and with screen readers. The bar mirrors for right-to-left paragraphs. Flag: text.ruler.

## Language and direction

Set the language of a selection or a paragraph, or mark it Do not check spelling. Spell check checks each part in its own language. The right-to-left and left-to-right buttons set the direction. Start and end alignment follow it. Hyphenation follows the language. Flag: text.language.

## Footnotes and symbols

- Insert footnotes and endnotes. They number in reading order, can restart per document or at each Heading 1, and are edited in an area under the page. Jump between the reference and the note.
- The Symbol dialog searches by name or code. Alt+X turns hex digits into a character and back. Nonbreaking spaces, dashes, and soft hyphens have commands.
- Show formatting marks draws paragraph, space, and tab marks. It does not change the page. Flag: text.symbols.

## Comments and suggestions

New comment covers the selection or the word at the caret. The comments pane posts, replies, resolves, reopens, deletes, and goes to the text. Press Ctrl+Shift+E (with the Word keys) to track changes. Typing, deletions, and format changes are recorded. Accept or reject one change, all of them, or all by one person. Choose Simple, All, or No markup. Compare lists formatting changes. Paragraph splits, tables, and code blocks are not tracked yet. Flag: text.review.

## Copy and paste

Copying writes inline formatting that Word and Google Docs keep, and plain text beside it. Paste keeps the source formatting from Word, Google Docs, and OneNote. A Paste Options notice switches between keep source, merge, and plain text. Settings sets a default for each source. Ctrl+Shift+V always pastes plain text.

## Word files

Import and export keep these formats. See [Import and export](import-and-export.md#word-files-and-text-formatting).

## Shortcuts

| Do this | Press |
|---|---|
| Open the Font pane | Ctrl+D |
| Track changes (Word keys) | Ctrl+Shift+E |
| Paste plain text | Ctrl+Shift+V |
| Hex digits to a character and back | Alt+X |
| Any other format command | Ctrl+K, then its name |
