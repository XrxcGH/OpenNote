# OpenNote help

Short guides for using OpenNote, one for each area of the app. They describe beta 4 (0.1.0-beta.4). Nobody has tried most of these features by hand yet, so [tell us](../testing/beta-4-checklist.md#reporting-a-failure) if a step does not work as written.

Every picture is a real screenshot. [The screens folder](../screens/README.md) has all of them, in light and dark.
